# Safe Visa Notifier — Казахстан, Польша, Армения

Telegram-бот безопасно отслеживает публичную таблицу **Global Visa Wait Times** Госдепартамента США.

## Что умеет

- выбор через кнопки: Казахстан, Польша, Армения;
- города: Almaty, Astana, Warsaw, Krakow, Yerevan;
- несколько отслеживаний одновременно;
- типы виз: B1/B2, F/M/J, H/L/O/P/Q, C/D/C1/D;
- пользователь выбирает порог ожидания;
- бот сообщает, когда опубликованный показатель уменьшился или достиг порога.

## Чего бот не делает

- не входит в личный кабинет;
- не хранит логин и пароль;
- не обходит CAPTCHA и защиту сайта;
- не кликает календарь;
- не бронирует и не переносит запись автоматически;
- не заявляет, что конкретный слот точно свободен.

Публичная таблица показывает ориентировочное ожидание, а не точный календарь. После уведомления пользователь самостоятельно проверяет официальный кабинет.

## Запуск на Windows в VS Code

### 1. Установите Python

Скачайте Python 3.11 или 3.12. При установке отметьте **Add Python to PATH**.

Проверьте в PowerShell:

```powershell
python --version
```

### 2. Создайте Telegram-бота

1. В Telegram откройте `@BotFather`.
2. Отправьте `/newbot`.
3. Придумайте название и username.
4. Скопируйте токен.

Никому не отправляйте токен.

### 3. Откройте проект

Распакуйте архив, затем в VS Code выберите:

`File → Open Folder → safe_visa_notifier`

### 4. Создайте файл `.env`

В корне проекта скопируйте `.env.example`, переименуйте копию в `.env` и вставьте токен:

```env
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
CHECK_INTERVAL_MINUTES=360
DB_PATH=visa_bot.sqlite3
```

### 5. Установите зависимости

В VS Code выберите `Terminal → New Terminal` и выполните:

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Если PowerShell запрещает активацию:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.venv\Scripts\activate
```

### 6. Запустите

```powershell
python -m app.main
```

После строки о polling откройте своего бота в Telegram и отправьте `/start`.

## Чтобы бот работал постоянно

При закрытом VS Code бот выключится. Для постоянной работы его нужно запустить на VPS или другом постоянно включённом компьютере. Не устанавливайте интервал слишком маленьким: публичные данные не являются календарём реального времени. Рекомендуемый интервал — 360 минут.

## Обновление старой версии

Если рядом остался старый файл `visa_bot.sqlite3`, его можно удалить перед первым запуском новой версии. Тогда база будет создана заново.
